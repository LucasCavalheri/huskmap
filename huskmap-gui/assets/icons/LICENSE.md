# Icons

UI glyphs in this directory are generated from the free Hugeicons set.

- Source package: [`@hugeicons/core-free-icons`](https://www.npmjs.com/package/@hugeicons/core-free-icons) version **4.3.5**
- Style: stroke, 24x24 viewBox, stroke-width 1.5
- Homepage: https://hugeicons.com
- License: MIT (text below, copied from the package's `LICENSE.md`)
- Retrieved: 2026-09-23

Conversion: each icon's `[tag, attrs]` array from `dist/esm/<Name>Icon.js` was
serialized into a standalone `<svg viewBox="0 0 24 24" fill="none">`. Attribute
names were converted from camelCase to kebab-case and every `currentColor` was
replaced with `white` so the app can tint via a color filter. Geometry is unchanged.
